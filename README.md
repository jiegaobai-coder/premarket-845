# 8:45 盘前分析

每天 8:45 的观察入口。不是再读一遍 Schwab 期权历史 PDF，而是把昨天 16:00 的异动，用今晨 OI 修正成：**今天先看谁、为什么看、还缺什么确认**。

PDF 仍保留在「PDF 存档」里，只作当天摘要和核对原文。

## 页面怎么用

- **今日关注**：按观察顺序排，不给笼统的“强烈看涨”。
- **昨日异动 → 今晨 OI 确认**：增强、削弱、撤销分开；**尚未更新**单独成组，不会混进“没有确认”。
- **周度／月度结构**：看哪些期限一致、哪些冲突、关键合约在哪。
- **等待价格确认**：资金已经留下仓，还缺股价站上、守住或收回哪个位置。
- **风险与分歧**：追高、结构冲突、临近财报、数据不完整。

Tab 负责分问题，Filter 负责缩小范围。每张卡片会写明它为什么出现在当前筛选结果里。

卡片固定顺序：

1. 昨天发现了什么
2. 今晨确认了什么
3. 为什么值得关注
4. 开盘后看什么
5. 什么情况会使判断失效

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:8451](http://127.0.0.1:8451)。
