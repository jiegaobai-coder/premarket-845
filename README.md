# 8:45 盘前分析

每天 **8:45 打开来看** 的观察入口。不是再读一遍 Schwab 期权历史 PDF，而是把昨天 16:00 的异动，用今晨 OI 修正成：**今天先看谁、为什么看、还缺什么确认**。

## 什么时候更新？

**不会在每天 8:45 自动刷新。**

- **8:45**：你打开页面看盘前的时刻。
- **数据**：跟着当天那份 `schwab_options_history_YYYYMMDD_HHMM.pdf` 走。你现在这份是 **2026-09-18 08:49** 生成的。
- **换新的一天**：把新 PDF 整理进 `src/data/briefing.ts` 之后，首页才会变成新的 8:45。打开网页本身不会到点换名单。

PDF 仍保留在「PDF 存档」里，只作当天摘要和核对原文。

## 怎么打开（Windows）

1. 电脑上先装好 [Node.js LTS](https://nodejs.org/)。
2. 这个项目放到任意文件夹（不要只拷一个 exe）。
3. 双击 **`打开8-45盘前.exe`**，或双击 **`打开8-45盘前.bat`**。
   也可以把 exe 放到桌面。若 exe 不在项目文件夹里，在旁边放一份 **`打开8-45盘前.dir`**，里面写项目路径（一行）。
4. 浏览器会打开 [http://127.0.0.1:8451](http://127.0.0.1:8451)。关掉那个黑窗口，页面就会停。

第一次会跑 `npm install`，稍等一会儿。

## 怎么放到你的 Windows 电脑（给 Codex 接手）

现在这份代码在 Cursor 云里的临时 Git 上。云端页面右上角右键 Copy，**不会**把 exe 放进 Windows 剪贴板，所以桌面没有 Paste。

正确做法：

1. 在 Cursor 里点 **Create repo**，把项目存成你自己的 GitHub / GitLab 仓库。
2. 在 Windows 上 clone 到本地，例如：

```bat
cd %USERPROFILE%\Documents
git clone <你的仓库地址> premarket-845
cd premarket-845
npm install
```

3. 双击项目里的 **`放到桌面.bat`**。它会把 `8-45盘前.exe` 拷到桌面，并写上项目路径。
4. 用 Cursor 或 Codex **打开这个本地文件夹**。权限用完后，Codex 接管的是你电脑上的这份代码，不是云虚拟机。

不要只拷一个 exe。exe 要能找到整个项目才能启动页面。

手动启动也可以：

```bat
npm install
npm run dev
```

然后浏览器打开 http://127.0.0.1:8451

## 页面怎么用

- **今日关注**：按观察顺序排，不给笼统的“强烈看涨”。
- **昨日异动 → 今晨 OI 确认**：增强、削弱、撤销分开；**尚未更新**单独成组，不会混进“没有确认”。
- **周度／月度结构**：看哪些期限一致、哪些冲突、关键合约在哪。
- **等待价格确认**：资金已经留下仓，还缺股价站上、守住或收回哪个位置。
- **风险与分歧**：追高、结构冲突、临近财报、数据缺口。

Tab 负责分问题，Filter 负责缩小范围。每张卡片会写明它为什么出现在当前筛选结果里。

卡片固定顺序：

1. 昨天发现了什么
2. 今晨确认了什么
3. 为什么值得关注
4. 开盘后看什么
5. 什么情况会使判断失效
